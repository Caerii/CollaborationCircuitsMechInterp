# Study 3: Multi-Agent Interference

Test the core thesis: do representations of multiple agents interfere, and does
interference predict failures?

## Hypotheses

- H3.1: Belief tracking accuracy decreases as number of agents increases (1→5)
- H3.2: Representation overlap predicts errors (logistic regression)
- H3.3: Information chain degradation is caused by agent representations overwriting each other
- H3.4: Self-belief and other-belief use different circuits (≥30% non-overlap)
