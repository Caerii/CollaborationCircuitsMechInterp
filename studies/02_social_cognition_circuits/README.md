# Study 2: Social Cognition Circuits — Beyond Sally-Anne

Map circuits for a taxonomy of 6 social cognition tasks. Test whether circuits
are modular (task-specific) or shared.

## Hypotheses

- H2.1: Different tasks recruit partially distinct circuits with shared agent-binding core
- H2.2: Explicit tasks have stronger, more localized circuits than implicit tasks
- H2.3: Communication→belief-update pathway exists but has weak feature amplitudes

## Task Taxonomy

1. False Belief
2. Knowledge Attribution
3. Intention Reading
4. Perspective Taking
5. Communication Tracking
6. Belief Update (the hard one)
